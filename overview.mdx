---
title: Overview
description: |
  Ctrlplane is an open-source deployment orchestration platform that coordinates
  how your software versions are deployed across environments and infrastructure.
---

Ctrlplane provides centralized orchestration for deployment workflows, ensuring
controlled rollouts and policy-based progression across diverse infrastructure.

## Key Features

- **CI/CD Integration**: Triggers deployments from your existing CI/CD pipelines
  (GitHub Actions, GitLab CI, Jenkins, etc.)
- **Policy-Based Orchestration**: Define rules for approvals, sequencing,
  concurrency, and environment progression
- **Deployment Versions**: Track and manage multiple versions of your software
  across environments
- **Environment Management**: Organize resources into logical environments with
  different policies
- **Resource Discovery**: Automatically discover and sync infrastructure from
  cloud providers
- **Job Agents**: Execute deployment tasks in your infrastructure via pluggable
  agents
